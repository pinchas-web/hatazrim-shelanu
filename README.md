# מנוע המערכות

מנוע אחד שבונה כל מערכת מתוך קובץ המבנה (`blueprint.js`). כדי להקים מערכת חדשה מעתיקים את כל התיקייה, כותבים `blueprint.js` לפי `../blueprint-format.md`, ופותחים את `blueprint.html` כדי להציג ללקוח.

## הקבצים

| קובץ | מה הוא | נוגעים בו? |
| --- | --- | --- |
| `blueprint.js` | מבנה המערכת: טבלאות, שדות, דשבורד, תפקידים, דוגמאות | כן, לכל מערכת |
| `blueprint.html` | דף מבנה המערכת שמוצג ללקוח, עם שלושה סגנונות בתוך טלפונים | לא |
| `index.html` | המערכת עצמה | לא |
| `app.js` | המנוע: ניווט, רשימות, לוח עמודות, כרטיסים, טפסים, דשבורד, הגדרות, ייצוא, שמירה | לא. שיפורים כלליים נכנסים כאן לכל המערכות |
| `app.css` | הרכיבים וחמש ערכות הנושא (`library/styles.md`) | רק כדי להוסיף ערכת נושא חדשה |
| `custom.js` | הרחבות למערכת הזו בלבד | כן, כשצריך |
| `config.js` | חיבור ל-Supabase. ריק = מצב הדגמה | כשמחברים לענן |
| `setup.sql` | מסד הנתונים. אותו קובץ לכל המערכות | לא. מריצים פעם אחת בכל פרויקט Supabase |
| `manifest.webmanifest`, `sw.js`, `icon.svg` | התקנה למסך הבית, ועבודה עם קליטה חלשה | שם ואייקון לכל מערכת |

## מה המנוע עושה לבד

- **דשבורד**: ברכה, עד 4 מספרים (ספירה, סכום, היום, השבוע, החודש), "מחכה לטיפול", ו"בימים הקרובים".
- **רשימה לכל טבלה**: חיפוש, סינון לפי סטטוס עם מונים, מיון חכם (קודם מה שמאחר, אחר כך הקרוב, ובסוף מה שסגור), וכפתור הוספה צף.
- **לוח עמודות** לכל טבלה עם `board: true`.
- **כרטיס פרטים**: שינוי סטטוס בלחיצה, חיוג, וואטסאפ ומייל (גם מהלקוח המקושר), כל השדות, ורשימה של כל מה שקשור לרשומה.
- **טפסים** לפי סוג השדה, עם בדיקת שדות חובה, טלפון ומייל.
- **מחיקה עם ביטול** למשך 5 שניות.
- **הגדרות**: שם, סגנון וצבע, ייצוא לאקסל, ומחיקת נתוני הדוגמה.
- **ענן**: כניסה במייל, צוות עם תפקידים, ותמונות ב-Supabase.

## הרחבות ב-`custom.js`

למסך שהמנוע לא עושה, כמו דוח או חישוב מיוחד:

```js
LazyApp.view('report', (params, h) => {
  const jobs = h.rows.jobs || [];
  const total = jobs.filter(j => j.status === 'הושלמה').reduce((a, j) => a + (+j.price || 0), 0);
  return `${h.top('דוח חודשי')}
    <section class="card set"><h3>סך הכל הכנסות</h3><p class="kpi"><b>${h.money(total)}</b></p></section>`;
});
```

ובקובץ המבנה, כדי שיופיע בניווט: `extraNav: [{ view: 'report', label: 'דוח', icon: 'chart' }]`.

משתמשים רק במחלקות שכבר קיימות ב-`app.css` (`card`, `set`, `list`, `item`, `kpi`, `btn`, `chip-btn`, `status`), כדי שהמסך יקבל לבד את הסגנון שנבחר.

## חיבור לענן

1. בעל העסק פותח חשבון חינמי ב-Supabase ופרויקט חדש.
2. מריצים את `setup.sql`.
3. ב-Authentication, כותבים את כתובת המערכת ב-Site URL וב-Redirect URLs.
4. ממלאים ב-`config.js` את כתובת הפרויקט ואת המפתח הציבורי.
5. בכניסה הראשונה נוצר העסק, ובעל העסק הופך ל-owner. כדי להוסיף עובד, מוסיפים את המייל שלו לטבלה `members` עם תפקיד `member`. בהמשך זה ייעשה ממסך הצוות.

## מה עוד לא נבדק

הקוד של הענן (כניסה, צוות, תמונות) כתוב אבל עוד לא נבדק מול פרויקט Supabase אמיתי. מצב ההדגמה נבדק מקצה לקצה.
